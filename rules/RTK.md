# RTK (Rust Token Killer)
A hook silently rewrites Bash commands through `rtk`, saving 60 to 90 percent of the output tokens. Run these directly, they are not rewritten: `rtk gain` for savings, `rtk discover` for missed opportunities, `rtk proxy <cmd>` to bypass filtering when debugging.
If `rtk gain` is missing, the name has collided with the unrelated Rust Type Kit package.
